# Spectacle 2

A menu-bar window manager for macOS: it moves and resizes other apps' windows to fixed layouts on demand.

## Language

**Window Action**:
One of the fixed ways Spectacle 2 can move or resize a window, such as Left Half, Next Display or Undo Last Move.
_Avoid_: command, layout, snap

**Target Window**:
The focused window of the frontmost app, which every Window Action applies to, whether it comes from a shortcut or the Status Menu.
_Avoid_: active window, current window

**Shortcut**:
The key combination bound to a Window Action; the user can change or clear it.
_Avoid_: hotkey, keybinding

**Status Menu**:
The dropdown that opens from Spectacle 2's icon in the menu bar.
_Avoid_: menu bar menu, tray menu

**Drag Snap**:
Moving a window by dragging it to a screen edge or corner, which applies the matching layout when the mouse is released.
_Avoid_: edge snapping
