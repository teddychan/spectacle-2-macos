## Project rules

- `SUFeedURL` in `App/Info.plist` and the support link in `Sources/Spectacle2/AboutConfig.swift` name the pre-rename repo `teddychan/spectacle-2` on purpose. DragonKit CONFORMANCE §R15 requires the support repo to equal the page slug, and GitHub redirects the old URLs, so leave both until DragonKit accepts the `-macos` suffix.
